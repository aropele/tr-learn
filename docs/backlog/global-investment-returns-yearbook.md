# Global Investment Returns Yearbook: editions to ingest

Backlog of the Dimson–Marsh–Staunton *Global Investment Returns Yearbook* (long-run returns by country and asset class since 1900), collected 2026-10-16. Free documents only: public summary editions for 2017–2026 and the free Yearbooks for 2008–2016. Each row's title was read from the PDF cover, except 2024 (UBS landing page and filename) and 2020 (Wayback content not opened).

Publisher folder = publisher of the document at the time: `--publisher ubs` (2024+), `credit-suisse` (2009–2023), `abn-amro` (2008). This is institutional research, so no `--popular`.

- **Official UBS PDFs (2024–2026)** answer 403 to scripted fetches (Akamai). Open them in the browser and pass the file with `--file`.
- **Credit Suisse URLs are all dead** (they redirect to ubs.com or reset the connection). Rows link a third-party copy or Wayback; pass the dead official URL in `--notes` and the copy host with `--canonical-url` where no official URL survives.
- **Confirm dates from the cover.** Months come from the cover; UBS days come from the launch press release.
- **2011 and 2012:** the text layer is garbled, so the year comes from the filename and the hosting post.
- **2023:** the PDF prints the error "Extracted from: ... Yearbook 2022" on p. 3; keep it and flag it.
- **Gaps:** no free copy found for 2010, and ABN AMRO 2000–2007 were not searched.
- **Paid only:** full hardcopy Yearbooks 2017–2026 and the 2009–2016 Sourcebooks.
- **Backup Wayback captures of the official URLs:** 2023 `20250330093339`, 2022 `20241213193005`, 2021 `20250212093929`, 2019 `20240909041357`, 2017 `20190117102506`.

When a row is archived, set Status to its id.
