# Portfolio construction according to AQR and GMO

Curated reading path built with Claude on 2026-10-15 from AQR's research library (https://www.aqr.com/Insights/Research) and GMO's white papers (https://www.gmo.com/europe/research-library/); an index, not a source.

AQR and GMO answer the same questions as Vanguard and Bridgewater, but from two other angles. AQR is quantitative and evidence-driven: it sizes allocations from expected returns, diversifies across countries, factors and trend, and treats leverage and rebalancing as explicit choices. GMO is valuation-driven and contrarian: starting prices set future returns, so a strategic allocation should not stay static. AQR's "Sin a Little" partly answers GMO's case for timing.

Phases: 1 Framework → 2 Expected returns and valuation → 3 Diversification → 4 Inflation and tail risk → 5 Rebalancing

For the other views see [Portfolio construction according to Vanguard](../portfolio-construction/README.md) and [according to Bridgewater](../portfolio-construction-bridgewater/README.md).
